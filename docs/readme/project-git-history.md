# 查看项目分支图与提交记录

1. 在 Orca 中选择一个 Git 工作区，打开右侧 **Source Control** 面板。
2. 展开底部的 **Commits**（提交）区域。
3. 在历史记录范围中选择 **Project branch graph**（项目分支图），查看本地分支与远程跟踪分支的分叉、合并和提交记录。选择 **Current branch**（当前分支）可回到原有的工作区历史。
4. 点击提交查看差异；展开提交可查看文件列表。拖动提交面板上边缘可调整高度。
5. 点击 **Load more commits**（加载更多提交）每次增加 50 条，最多显示最近 200 条。刷新按钮重新读取当前范围。

此视图只读，不会切换分支、拉取远程或修改文件。远程分支显示的是执行主机最后一次 fetch 的结果。
SSH 工作区使用所属主机上的 Git 数据；旧版主机若尚不支持项目范围，会提示切回当前分支或更新主机。
纯文件夹工作区沿用原有行为，不显示 Git 提交图。范围选择不会改变源代码管理面板的分支比较基准。
